# 爪爪零食铺

奶油白与暖橘色的中文宠物零食商城前端。HTML、CSS、原生 JavaScript，无运行依赖或构建步骤。

## 本地预览

安装 Node.js（建议 20 或更高版本），在本目录执行：

```sh
npm start
```

打开 http://localhost:4173 。修改文件后刷新即可。若端口被占用，PowerShell 可使用 `$env:PORT=4174; npm start`。

```sh
npm test
```

## 功能

- 8 款示例商品，猫狗筛选、名称搜索、价格排序及空结果恢复。
- 商品卡片展示示例月销量，数据在 `store.mjs` 的 `monthlySales` 字段维护。
- 页面底部常驻购物车摘要，数量与合计随加购、修改、删除及模拟结算实时更新，可直接展开明细。
- 商品详情、数量选择、购物车增减删除、总价和 localStorage 持久化。
- 订单摘要、返回修改与模拟下单成功反馈；不会产生真实交易。
- 原生 dialog 键盘操作和焦点管理，手机双列布局，图片加载失败占位。
- `account.html` 提供邮箱注册 / 登录，邮箱不区分大小写，注册成功自动登录并返回商城；密码为 8–64 位。
- 账号使用 Web Crypto PBKDF2-SHA-256（每账号随机盐，210,000 次派生）保存校验值，不保存明文密码。登录状态使用 sessionStorage，同一标签页刷新保留。
- 游客可填写收货信息并模拟下单；登录用户可保存一个地址，下次自动带出。成功页展示商品、金额及收货信息。
- 地址必填：收货人（1–30 字）、中国大陆手机号、省 / 市 / 区县（各 1–30 字）、详细地址（5–120 字）。省市区手动填写。
- 结算草稿只保留在当前页面内存；返回购物车修改商品或关闭结算后重新进入可继续填写，刷新页面或切换账号后清除。游客地址不长期保存。
- 存储不可用时可在当前页面继续购物；数量上限为每款 99 件，金额以整数分计算。

## 文件

- `index.html` / `styles.css`：页面与响应式视觉。
- `app.mjs`：交互及对话框。
- `store.mjs`：示例商品、筛选与购物车模型。
- `account.html` / `account.mjs`：账号页面及其交互。
- `account-store.mjs`：演示账号、密码校验、会话及收货地址存储。
- `assets/`：本地照片、自制商品包装 SVG 与占位图。
- `server.mjs`：仅监听本机的静态预览服务器，只暴露页面所需资源。

品牌、商品、营养描述、价格与订单均为演示数据，不代表真实商品或商业承诺。横线价格仅为演示原价，无实际促销活动。

账号与地址仅保存在当前浏览器，不跨设备同步。此功能属于前端演示，不能提供真实身份认证；没有邮件验证、密码找回或真实交易。浏览器阻止存储时账号操作会显示错误，仍可继续游客购物。请通过 `npm start` 的本地地址或 HTTPS 访问账号页。
